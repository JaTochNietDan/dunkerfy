A FEW MINUTES TO SET UP

Give your Mac
a new vocabulary.

Dunkerfy reads visible notification banners using macOS Accessibility, then plays the sound for the first matching rule.

Read the setup guide ↗
  1. 1

    Allow Accessibility access

    Move the app to Applications, then enable Dunkerfy in System Settings → Privacy & Security → Accessibility.

  2. 2

    Keep the banner. Mute the original.

    Turn off each source app’s notification sound while keeping banners or alerts enabled. Dunkerfy plays additional audio; it cannot cancel the original.

  3. 3

    Create a rule and try it

    Choose an app, pick a sound, and save. Trigger a notification and check Activity. Add a keyword if you want a more specific match.

About this developer preview

This is an early developer preview for macOS 13+. The download is for Apple Silicon, Developer ID signed and Apple-notarized. Optional in-app updates use signed feeds and verified downloads.

Rule matching and simulated audio playback have been tested. Live capture of third-party notifications is not yet verified. Notification Center’s Accessibility layout can change across macOS versions.

Focus, disabled banners, and hidden previews can limit matching. If you try it, the issue tracker is the place to share what works—or what doesn’t.

A few good questions.

Does it replace an app’s original sound automatically?

No. Turn off the original notification sound in macOS or the source app’s own settings. Keep banners or alerts on so Dunkerfy can read them.

Will it work with every app?

It is designed around visible macOS Notification Center banners. Apps with their own notification UI, suppressed banners, and hidden message previews may not provide the information it needs. Live compatibility testing is still pending.

Can I use my own audio?

Yes. Import AIFF, WAV, MP3, M4A, or CAF files up to 20 MB. Dunkerfy copies them into its own library, so moving the original file will not break your rule.

Is this affiliated with Chirpy?

No. Dunkerfy is an independent, open-source implementation of per-app notification sound rules. It does not use Chirpy code or assets.
