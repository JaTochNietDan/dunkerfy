# Dunkerfy 0.2.1 — Developer preview

The compact native interface and 30-sound library from 0.2.0, now signed with Developer ID and notarized by Apple.

- Compact 964 × 620 light/dark interface with tighter sidebar spacing.
- Searchable sound library with the CC0 Wilhelm scream and 29 original effects.
- Apple Developer ID signing, hardened runtime, and a stapled notarization ticket.
- Signed Sparkle update feed and verified update downloads. Automatic checks and installation are opt-in.

For Apple Silicon, macOS 13 or later. Quit Dunkerfy, extract the ZIP, and move Dunkerfy.app to Applications, replacing the previous version. Existing rules and imported sounds are preserved. Users of 0.1.0 must install manually; 0.2.0 includes Check for Updates.

This remains a developer preview: live third-party notification capture and full update installation/relaunch testing are still pending. Notarization does not establish notification compatibility.
