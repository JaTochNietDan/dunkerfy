# Dunkerfy 0.2.2 — Startup permissions

Dunkerfy now requests macOS Accessibility access at startup when it is missing, instead of silently waiting for you to find the Settings page.

- Uses the native macOS permission prompt once per launch when access is missing. Already-authorized launches do not prompt.
- Opens Dunkerfy’s Settings page with an explanation of why access is needed and how to enable it.
- Shows live access status and resumes scanning when permission is granted. Revoking access stops scanning.
- The Accessibility settings button can request access again. Background polling never prompts.
- Automated smoke tests and UI previews do not request or change permissions.

Developer ID signed and Apple-notarized. Apple Silicon, macOS 13 or later. Use Check for Updates, or quit Dunkerfy and replace the app in Applications with the extracted download. Rules and imported sounds are preserved.

This remains a developer preview. Live notification capture, interactive permission grant/revoke, and full update installation/relaunch still require hands-on validation.
