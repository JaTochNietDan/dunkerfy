# Dunkerfy 0.2.0 — Developer preview

Adds a compact native redesign, 30 bundled sounds, and in-app updates using Sparkle 2.10.0, integrated directly from Rust.

- Compact 964 × 620 native light/dark UI with rounded panels and teal accents.
- Tighter sidebar spacing, smaller navigation buttons, and more compact headings.
- Searchable soundboard with Fun, Arcade, Calm, macOS, and Imported filters.
- Actual CC0 Wilhelm scream plus 29 original effects; previews and one-click rule drafts.
- Check for Updates in the app and menu bar.
- Dedicated Updates page with opt-in automatic checks and download/installation.
- Sparkle integration supports signed feeds and Ed25519-verified downloads before extraction. The production update feed is not live yet.
- Your rules and imported sounds remain in Application Support.
- Update checks never include notification content, rules, or imported sounds.

Download `Dunkerfy-0.2.0-macOS-arm64.zip`, extract it, and move Dunkerfy.app to Applications, replacing the previous version. Quit Dunkerfy before replacing it. Existing rules and imported sounds are preserved.

This preview requires manual installation; automatic updates are not available yet.

This build is for Apple Silicon and macOS 13 or later. Live third-party notification capture remains unverified. This preview is ad-hoc signed and is not Apple Developer ID signed or notarized. macOS Gatekeeper may block it; public signing and notarization setup is still pending.
