# Dunkerfy 0.2.0 — Developer preview

Adds a compact native redesign, 30 bundled sounds, and in-app updates using Sparkle 2.10.0, integrated directly from Rust.

- Compact light/dark UI with a sidebar, rounded panels, and teal accents.
- Searchable soundboard with Fun, Arcade, Calm, macOS, and Imported filters.
- Actual CC0 Wilhelm scream plus 29 original effects; previews and one-click rule drafts.
- Check for Updates in the app and menu bar.
- Dedicated Updates page with opt-in automatic checks and download/installation.
- Signed update feed and Ed25519-verified downloads before extraction.
- Your rules and imported sounds remain in Application Support.
- Update checks never include notification content, rules, or imported sounds.

Users of 0.1.0 must install this version manually once.

This build is for Apple Silicon and macOS 13 or later. Live third-party notification capture remains unverified. Signing/notarization setup is pending; do not publish this release as notarized until Apple has accepted the final artifact.
