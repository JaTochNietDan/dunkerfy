Dunkerfy gives visible macOS notifications sounds you choose, with per-app rules and optional keyword matching. It is a native AppKit application written in Rust.

### Included

- Ordered sound rules with enabled/disabled state, optional text matching, volume, and cooldown.
- Built-in macOS sounds plus imported AIFF, WAV, MP3, M4A, and CAF audio.
- Sound preview, simulated rule testing, and an in-memory activity log.
- Menu bar pause/resume and optional launch at login.
- Local processing, no account, and no notification uploads.

### Download and setup

Download **Dunkerfy-macOS-arm64.zip** for Apple Silicon, unzip it, and move the app to Applications. Follow the [setup guide](https://github.com/JaTochNietDan/dunkerfy#setup) to grant Accessibility access, keep banners enabled, and mute the source app’s original sound.

`SHA256SUMS` contains the download checksum. The source can be built locally with mise.

### Developer preview limitations

This is an early preview, not a verified stable release. The app is locally ad-hoc signed and **not Apple-notarized**, so macOS may block it. The downloadable binary is Apple Silicon only; Intel and older macOS versions are untested.

Eight rule/storage tests, lint, native UI construction, and simulated playback passed. **Live third-party notification capture remains unverified.** Notification Center’s Accessibility layout can change between macOS releases. Focus, disabled banners, and hidden previews can prevent matching.

Dunkerfy adds audio; it cannot cancel the original app’s sound. There is no automatic update mechanism in this release.
